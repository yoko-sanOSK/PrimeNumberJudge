# PrimeNumberJudge

商 $q$ の $\bmod 3$ を用いた概素数判定の高速走査＆精度評価プログラム（C++17）。

11 以上 $N$ 以下で下1桁が $r \in \{1, 3, 7, 9\}$ の整数 $n = 10q + r$ を、$a = q \bmod 3$ により判定する。

| $a$ | 概素数 | 合成数 |
|---|---|---|
| 0 | $10q+1,\ 10q+7$ | $10q+3,\ 10q+9$ |
| 1 | $10q+1,\ 10q+3,\ 10q+7,\ 10q+9$ | なし |
| 2 | $10q+3,\ 10q+9$ | $10q+1,\ 10q+7$ |

## ビルド

```sh
make            # g++ -std=c++17 -O3 -march=native
```

## 使い方

```sh
./probable_prime 1000                 # 通常モード：概素数を1行1個で列挙
echo 1000 | ./probable_prime          # 上限値を標準入力から取得
./probable_prime 1e9 --eval           # 評価モード（-e でも可）
./probable_prime 1e11 -e --repeat 3 --sieve-cap 0   # Phase 1 のみ計測
```

評価モードのオプション：

- `--repeat K`：Phase 1 の計測反復回数（既定 5、最小値と中央値を表示）
- `--sieve-cap X`：Phase 2 で篩を構築する上限値（既定 $2^{35}$。必要メモリ ≈ $N/16$ バイト）

## 評価モードの内容

- **Phase 1**：I/O・篩参照なしで走査し、概素数の個数・XOR チェックサム・実行時間を計測（チェックサムは DCE 防止を兼ねる）。
- **Phase 2**：奇数のみ・ビット圧縮の区分篩で真の素数表を構築し、`judge_from_qa` による独立判定と照合。
  混同行列（TP/FP/TN/FN）、正答率・適合率・再現率・偽陽性率、下1桁別内訳、篩の構築時間を出力。
  Phase 1 との個数・チェックサム一致、および TP+FP+TN+FN = M を自動検算する。

## 計測例（4コア環境、`-O3 -march=native`）

| $N$ | 提案走査 | 1候補あたり | 篩構築 | 適合率 | 正答率 | FN |
|---|---|---|---|---|---|---|
| $10^9$ | 68 ms | 0.17 ns | 724 ms | 19.07 % | 46.05 % | 0 |
| $10^{10}$ | 709 ms | 0.18 ns | 9.0 s | 17.06 % | 44.71 % | 0 |

TP はいずれも $\pi(N) - 4$（2, 3, 5, 7 を除く）と一致する。

## 数学的な性質

$10 \equiv 1 \pmod 3$ より $n \equiv q + r \pmod 3$ であり、判定ルールは「$n$ が 3 の倍数か」と同値である。
したがって概素数は「30 と互いに素な 11 以上の整数」に一致し、

- 合成数と判定されるのは 3 の倍数のみなので **FN = 0**（再現率 100 %）
- 適合率は素数定理よりおよそ $\dfrac{30/8}{\ln N}$ で、$N \to \infty$ で 0 に近づく
- 偽陽性率は $2/3$ に近づく
